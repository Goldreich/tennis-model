# Archived model versions

Frozen Tennis Model v1.0 remains fully available as the rollback and documentary
baseline. Its authoritative specification is
`docs/Tennis_Model_v1.0_Specification.md`, its configuration remains
`config/model_v1.yaml`, and its implementation and immutable historical locks
must not be deleted or rewritten after the v1.1 production promotion.

The earlier dynamic-anchor v1.1 candidate remains in
`docs/Tennis_Model_v1.1_Specification.md` with a superseded notice.
